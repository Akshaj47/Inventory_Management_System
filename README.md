# Inventory_Management_System

Developed a desktop-based Inventory Management System using Python (Tkinter), SQLite, and DBMS principles.
Designed a dashboard for managing employees, suppliers, categories, products, and sales.
Implemented CRUD operations for efficient data management.
Used SQLite database for secure and structured storage of inventory-related information.
Incorporated user authentication and role-based access control for enhanced security.
Integrated real-time search and filtering features to improve usability.
Developed an interactive UI with Tkinter and Pillow for better user experience.
